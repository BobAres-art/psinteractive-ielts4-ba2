Easy Rule Guide
1st Conditional: Real Possibility

Use for realistic plans and future outcomes.

If + Present Simple, ... will + Verb
"If it rains, I will take an umbrella."
2nd Conditional: Imaginary Wish

Use for dreams or unreal present/future situations.

If + Past Simple, ... would + Verb
"If I had more time, I would travel more."
Comma Rule: Use a comma only when starting with If.
• "If it rains, we will stay home."
• "We will stay home if it rains."
