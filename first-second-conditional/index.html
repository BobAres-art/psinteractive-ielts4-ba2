Structural Guide & Usage
First Conditional: Real Possibility

Used for real situations and their likely results in the future.

If Clause
If + Present Simple
Main Clause
will / won't + Verb
Example: "If it rains tomorrow, I will take an umbrella."
Second Conditional: Imaginary Situation

Used for imaginary or unreal situations in the present or future.

If Clause
If + Past Simple
Main Clause
would / wouldn't + Verb
Example: "If I had more time, I would travel more."
Comma Tip

Put a comma after the If clause when it comes first:
"If it rains, we will stay home."
No comma is needed when if is in the middle:
"We will stay home if it rains."
